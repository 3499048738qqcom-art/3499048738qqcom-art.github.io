# 我是侯学宇

我叫侯学宇。侯，是时候的侯去掉竖心旁；学，是学习的学；宇，是宇宙的宇。从小到大，我总被人问起名字的含义，我也认真想过 —— 大概是长辈希望我学遍天下、胸怀宇宙吧。这个期望不小，我背着它走了这些年，不敢说做到了几分，但至少没敢停下脚步。

我是个什么样的人呢？说实话，这个问题我到现在也没有完全确定的答案。有时候我觉得自己很外向，人多的场合也能聊得热火朝天；有时候又只想一个人待着，戴上耳机，世界与我无关。这种矛盾大概不是我独有，但我花了很久才接受它 —— 人本来就不是非黑即白的，能在热闹和安静之间自由切换，也算是一种本事。

我有一个特点，说不上是优点还是缺点：爱较真。遇到不懂的事情，我非得弄明白不可；觉得不对的事情，也忍不住要指出来。有人说我这样太累，也有人说这叫有原则。我自己倒觉得，在这个所有人都忙着 "差不多就行" 的世界里，较点真没什么不好。当然，我也在学着分场合 —— 有些事值得死磕，有些事笑笑就过去了，这个分寸感，我还在练。

我喜欢的东西挺杂的。读书是其中一样，什么都读一点，小说、历史、科普，甚至偶尔翻翻哲学，虽然大半看不懂。我总觉得，每本书都是一扇窗，推开了就能看到不一样的风景，哪怕只是瞥一眼，也比困在自己的小世界里强。我也喜欢写东西，不是为了成为作家，就是觉得有些想法不写下来会烂在肚子里，写出来了，才算真正属于自己。

至于未来，我没有太宏大的规划。我不想说 "我要成为什么样的人" 这种话，因为我连明天想吃什么都经常决定不了。但有一点是确定的：我想做一个诚实的人，对别人诚实，对自己更诚实。这个世界套路太多，真诚反而成了稀缺品，我想守住它。我也想一直保持好奇，对未知的事物保持热情，不要活成一个什么都见过、什么都不相信的人。

我是侯学宇，一个还在摸索中的普通人。有缺点，有迷茫，也有一点点不肯妥协的倔强。我不知道以后会变成什么样子，但我希望回头看的时候，能对自己说一句：还行，没白活。

这就够了。
